Example Business

This page represents a completely unrelated business's own website — it has no framework, no build step, and no knowledge of Arbor beyond the one <script> tag at the bottom of this file.

A "Reserve a table" button should appear in the bottom-right corner. Clicking it opens the real booking flow in a modal — sign in with an email code, pick a service, book — without leaving this page.

Running this locally: replace YOUR_DEPLOYMENT_URL below with wherever your stack is running (e.g. http://localhost:3000 for a local make start), then open this file directly in a browser. The deployment must run tenancy.mode: "single" — see README.md for details.
